用一个 HTML 文件做一个完整的 3D 街机赛车游戏，使用 Three.js（从 CDN 加载，不使用其他库，不用构建工具，不使用任何外部素材）。重要：只输出一个文件：index.html

- 所有 HTML、CSS 和 JavaScript 都放在这一个文件里
- 不要创建任何其他文件
- 不要使用 React、TypeScript 或任何框架
- 最终文件必须能通过双击 index.html 直接运行

赛道：用简单几何体（一条带状路面网格或首尾相连的分段）搭一条环形赛道，边界清晰可见，让玩家能分辨出可行驶路面的范围

- 至少有几个弯道，再加一两处起伏或减速弯，不能只是个椭圆
- 赛道周围要有简单的场景（树木、护栏或类似的低多边形物体），别让世界显得空荡荡

玩家赛车：第三人称追尾镜头，平滑跟随车辆

- 街机式驾驶手感：加速、刹车、转向，高速过弯时有一定漂移/侧滑（不需要完整的物理引擎，简化的街机模型即可）
- 操作：W/上 = 加速，S/下 = 刹车/倒车，A/D 或 左/右 = 转向
- 要有速度感的视觉反馈（镜头视场角变化、运动模糊或粒子尾迹都可以，选一种）

比赛：3 辆由 AI 控制的对手车，沿路径点或类似的简单寻路方式沿赛道行驶，速度各不相同

- 圈数统计：检测玩家越过起点/终点线的时刻并计圈，跑完 3 圈后结束比赛
- 一个实时名次指示（第 1/第 2/第 3/第 4），随车辆相互超越而更新

界面：HUD 显示当前圈数（如 "第 2/3 圈"）、名次和速度

- 开赛倒计时（3、2、1、GO）
- 比赛结束画面显示最终名次，并带一个重新开始按钮

代码：所有内容都放在 <script> 和 <style> 标签内。不要解释。不要 markdown。不要拆分文件。只返回完整的 index.html 代码，并通过 CDN 的 script 标签加载 Three.js。
